# MERN E-Commerce Application

## Project Overview

A full-stack e-commerce web application built with the MERN stack, featuring a customer-facing store and an admin dashboard for managing products and orders.

---

## Objectives

- ** Createing a full-stack e-commerce website using the MERN stack (MongoDB, Express, React, and Node.js).
- ** Users can browse and purchase products.
- ** The website have features such as product search, product details, shopping cart
- ** Admin dashboard where admin can manage orders, website and products

---

## Technologies Used

### Frontend

- ** React (Vite)
- ** React Router
- ** Axios
- ** Custom CSS

### Backend

- ** Node.js
- ** Express.js
- ** MongoDB (Atlas)
- ** Mongoose

---

## Main Features

### Customer Interface

- ** Browse available products
- ** Add and remove items from cart
- ** View cart summary and total price
- ** Checkout system with shipping form
- ** Cash on Delivery order placement

### Cart Management

- ** Add/remove/update product quantities
- ** Automatic total calculation

### Order System

- ** Create orders from checkout page
- ** Store orders in MongoDB
- ** Include customer and delivery information
- ** Calculate total order amount

### Admin Dashboard

- ** View all orders
- ** Display customer and delivery details
- ** Switch between table and card view
- ** Update order status
- ** Add products
- ** Delete products
- ** Manage product visibility on Home page
- ** Upload images (Cloudinary)
- ** Manage past reviews (not completed for the time being)
